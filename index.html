A few useful answers

Before you get started.

Is MyGreeting free?

Yes. There is no additional MyGreeting purchase, subscription or account. Your organisation needs its own Microsoft 365 environment with SharePoint Online.

Can I install it from the SharePoint Store?

The store listing is being prepared. Until certification and publication are complete, the public installation guide describes the administrator-managed package route. We’ll add the store link here when the listing is available.

Where do employee dates come from?

You can use the signed-in employee’s Microsoft 365 profile or a same-site SharePoint employee list. Optional birthday and employment dates may be unavailable in the profile. The normal greeting still works using the SharePoint name.

What happens if a message list is deleted or damaged?

The normal greeting remains available. Editors can reconnect a list, restore a deleted list through the site recycle bin if it is still recoverable, or create a replacement. Safe repair adds missing setup; conflicting columns or other custom forms require an administrator. Export backups to preserve your messages.

Does it refresh the page automatically?

No. Message rotation happens when the page opens or reloads. Viewer-local and fixed named time zones are available for scheduled messages.

Which SharePoint environments are supported?

Modern SharePoint Online pages. MyGreeting does not advertise support for Teams tabs, classic SharePoint pages or SharePoint Server.
