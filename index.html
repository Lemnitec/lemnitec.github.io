SharePoint web part

MyGreeting

A configurable, personalised greeting for modern SharePoint pages. Welcome employees with time-aware messages, important moments and optional workplace announcements.

Installation guideConfiguration guide

One useful welcome, built into Microsoft 365

Personal greetings

Use the signed-in employee’s first name or full name, with automatic morning, afternoon and evening text.

Employee moments

Optionally show birthday, work-anniversary and new-starter greetings from Microsoft 365 or a SharePoint employee list.

Workplace messages

Schedule recurring or one-time subtitles using a native SharePoint list controlled by your organisation.

Designed for tenant control

MyGreeting runs in the customer’s Microsoft 365 tenant. It has no Lemnitec backend, telemetry or advertising network. Optional employee and message data remain in Microsoft 365 and are accessed with the signed-in user’s existing permissions.

  • Modern SharePoint Framework solution
  • SharePoint theme and responsive-layout support
  • No arbitrary HTML or script configuration
  • No separate Lemnitec account required
  • Free to install and use
Administrator required. A Microsoft 365 or SharePoint administrator must install the package and approve its delegated Microsoft Graph User.Read request if Microsoft 365 profile features will be used.
