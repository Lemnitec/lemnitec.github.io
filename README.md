# Lemnitec public documentation

Static public product, privacy, terms, support and documentation pages for Lemnitec software.

## MyGreeting pages

- Product: `/`
- Privacy: `/privacy/`
- Terms/EULA: `/terms/`
- Support: `/support/`
- Installation: `/docs/installation/`
- Administrator guide: `/docs/admin/`

The site contains plain HTML and CSS so it can be served directly by GitHub Pages without a build step.

## Publishing

In the repository settings, configure GitHub Pages to deploy from the `main` branch and repository root. After merging a change, verify every public HTTPS URL before referencing it in a Microsoft Marketplace submission.

Legal pages must be reviewed and approved by an authorised Lemnitec representative before publication.
