Configure MyGreeting

Edit the SharePoint page, select MyGreeting and open Edit properties. Settings are stored with the web part on that page.

Greeting

  • Automatic: configure morning, afternoon and evening text. MyGreeting uses the employee’s browser-local hour.
  • Custom: show one fixed greeting.
  • Name: show first name, full name or no name.
  • Presentation: configure subtitle, emoji, date, week number, alignment and spacing.

Employee-data source

Microsoft 365 profile

This recommended option reads configured fields for the signed-in user through delegated Microsoft Graph User.Read. Supported fields are given name, display name, birthday, employee hire date, job title, department and office location. Empty or unavailable fields are omitted.

SharePoint employee list

Select a same-site custom SharePoint list and map its columns:

  • A required single-value Person or Group column identifying the employee.
  • Optional single-line text columns for preferred name, job title, department and office location.
  • Optional date columns for birthday and employee start date.

MyGreeting queries only the row whose Person column matches the signed-in SharePoint user. Users must have permission to read the relevant item.

No employee source

Use SharePoint’s available current-user name without optional employee moments or profile details.

Personal moments

Birthday, work-anniversary and new-starter messages can be enabled independently. Birthday takes priority over work anniversary, which takes priority over the new-starter message. Anniversary messages appear after at least one completed year and may use {years}.

Editor-only preview modes let page editors check each state without changing live employee information. Published pages return to live data.

Name correction

When enabled, employees can save a preferred greeting name during the initial 30-day prompt. The value remains only in that browser’s local storage and can be reset. It is not written to Microsoft 365 or sent to Lemnitec.

Workplace messages

  1. Turn on Workplace messages.
  2. Choose Create message list. The page editor must have permission to manage lists.
  3. Open Manage messages in SharePoint and add content using SharePoint’s standard forms.

The native list supports daily rotation, selected weekdays, a day of the month, date ranges and one-time schedules. Higher priority values take precedence. Equal-priority messages rotate deterministically by day.

List permissions, versioning, retention and content governance remain under the customer’s SharePoint controls.

Safe fallback behaviour

If Graph access, a profile field, list, row or permission is unavailable, MyGreeting continues with the standard greeting wherever possible. Editors receive configuration status in the property pane without exposing diagnostic details to normal page visitors.

Recommended validation

  • Publish and reload the page after configuration.
  • Test with a normal employee account.
  • Test populated and empty profile fields.
  • Test inaccessible or missing lists.
  • Test light/dark themes, 200% zoom and a narrow viewport.
  • Navigate interactive controls by keyboard.
