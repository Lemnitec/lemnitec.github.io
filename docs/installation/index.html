Install MyGreeting

This guide is for Microsoft 365 and SharePoint administrators. MyGreeting supports modern SharePoint Online pages.

Before you begin

  • Obtain the official lemnitec-welcome.sppkg package from Microsoft Marketplace or another Lemnitec-authorised source.
  • Use an account that can manage the tenant App Catalog.
  • Choose a modern SharePoint site and page for validation.
  • Plan who may edit the page and any optional SharePoint lists.

1. Add the package

  1. Open the tenant App Catalog and its Apps for SharePoint library.
  2. Upload lemnitec-welcome.sppkg.
  3. Review the package information and choose Deploy.
  4. For an upgrade, replace the existing package. The stable solution and component identifiers preserve existing page instances.

2. Approve Microsoft Graph access

MyGreeting requests delegated Microsoft Graph User.Read. It uses this only for selected fields of the signed-in user. A SharePoint administrator should review and approve the pending request in the SharePoint administration area for API access.

If the request is not approved, MyGreeting still provides a safe fallback using available SharePoint page-context information. Microsoft 365 profile moments and details will not be available.

3. Add the app to a site

  1. Open the target SharePoint site.
  2. Open Site contents, choose to add an app, and add MyGreeting.
  3. Wait for installation to complete before editing the page.

4. Add the web part

  1. Open a modern SharePoint page and select Edit.
  2. Add a web part and search for MyGreeting.
  3. Add it to the desired section.
  4. Open Edit properties, review the defaults and publish the page.

5. Validate the installation

  • Test as a normal signed-in user, not only as an administrator.
  • Confirm the greeting changes correctly for the browser-local time.
  • Test a narrow layout and the tenant’s light and dark themes.
  • If profile features are enabled, confirm only the signed-in user’s selected data is shown.
  • Confirm optional failures fall back to the normal greeting.
