Common issues

The web part is not available

Confirm that the package is deployed in the tenant App Catalog and that the app has been added to the current site. Refresh the page after installation.

Microsoft 365 profile information is missing

Confirm that the delegated Microsoft Graph User.Read request is approved. Optional fields must also be populated in the signed-in user’s Microsoft 365 profile. MyGreeting falls back safely when fields are unavailable.

A SharePoint employee row is not found

Confirm the selected list and column mappings, ensure the Person column contains the signed-in user, and verify that the user can read that item.

Workplace messages are not displayed

Confirm that workplace messages are enabled, the selected list is accessible, the message is enabled, and its schedule currently qualifies. Higher-priority messages take precedence.

Name correction does not follow the user to another device

The optional corrected name is intentionally stored only in the current browser. It is not synchronized to Lemnitec or Microsoft 365.

Security reports

Send suspected security vulnerabilities privately to info@lemnitec.com. Include the affected version, reproduction steps and expected impact. Do not disclose vulnerabilities or personal information publicly.
